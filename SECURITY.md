# Security

Do not include credentials, private data, access tokens, or private keys in an issue, pull request, result table, prompt cache, or reproduction log.

For a sensitive report, use a private GitHub security advisory when it is enabled for the repository, or contact the corresponding author listed in AUTHORS.md. Describe the affected release and the minimum steps needed to reproduce the issue without disclosing a live secret.

This is a research prototype. Model-generated rules are evaluated candidates, not a security boundary. Optional external validators and model calls should run in environments appropriate to their inputs and credentials.

No credentials are required for the released offline verification command.
